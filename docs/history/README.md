# Implementation history

Historical records preserve prior plans, decisions, and reported observations. They are not current instructions, live status, or proof that a check still passes. Consult [domain context](../context.md), [architecture](../architecture.md), and [design](../design.md) for current contracts.

- [Workout-first redesign](workout-first.md): canonical per-set template targets, interaction decisions, and the original delivery context.
- [Workout-first audit trail](../../.audit/workout-first.tsv): recorded implementation trail associated with that effort.

When adding an entry, identify the effort or date, distinguish planned work from observed results, and link to the current contract for any rule that still applies. Keep useful original evidence when a later decision supersedes it.
