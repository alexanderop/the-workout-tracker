# Audit working files (historical)

These files were produced by earlier agent-driven planning, design and review runs and were previously kept in `.audit/` at the repository root. They are evidence of how past decisions were reached. They are **not** current instructions, open task lists or live status. Plans, briefs and checklists here may describe work that was later changed, replaced or never done, and some reference paths that no longer exist.

For current rules read the [glossary](../../glossary.md), [domain context](../../context.md), [architecture](../../architecture.md), [design](../../design.md) and [workflows](../../workflows.md).
